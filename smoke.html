AGENT CLOUD · BACKEND SDK CHECK

GlitchTip 백엔드 연결 확인

Node.js 테스트 앱에서 서버 오류를 발생시키고 GlitchTip의 백엔드 프로젝트에서 수신 여부를 확인하세요.

서비스 환경변수 GLITCHTIP_SMOKE_TOKEN에 설정한 값을 입력하세요.

처리되지 않은 Promise

Request timed out 오류가 백엔드 프로젝트에 도착하는지 확인하세요.

처리되지 않은 예외

undefined.map 예외를 발생시킵니다. 이 요청은 Node 프로세스를 종료하므로 마지막에 실행하세요.

콘솔 오류

Network Error를 서버 로그에 기록합니다. 로그와 오류 이벤트의 차이를 확인하는 비교 항목입니다.

처리된 HTTP 500

예외를 잡아 500 응답으로 반환합니다. 미처리 오류와 수집 여부를 비교하세요.

마지막 요청

아직 오류를 요청하지 않았습니다.
